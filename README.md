## Project Overview
ZoneSync is a smart agriculture management system designed to empower owners and farmers through:
- AI Diagnosis: Image-based plant disease detection.
- Automated Irrigation: Sensor-driven water management.
- Real-time Dashboard: Statistics for soil moisture, weather, and crop health.
- Task Management: Automated ticket system for agricultural actions.
